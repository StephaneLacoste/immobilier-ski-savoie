# immobilier-ski-savoie

# Projet final de formation Data Analyst - Analyse du marché immobilier des stations de ski de Haute-Tarentaise

## Objectif
Identifier les stations offrant les meilleurs profils de valorisation immobilière 
et les segments de marché à prioriser, à partir des transactions DVF 2014-2025, 
des données de performance énergétique DPE 2021-2026 et des données altimétrique 
collectées via l'API Open-Meteo.

## Technologies
- Python (Pandas, Seaborn, Scikit-learn, NumPy, Matplotlib)
- Power BI
- API Open-Meteo

## Contenu
- `Projet_Marche_Immobilier_de_Haute_Tarentaise.ipynb` : Notebook d'analyse complet (EDA, modélisation Random Forest)
- `Presentation_PB(2).pbix` : Dashboard Power BI (5 pages)
- `Rapport_Marche_Immobilier_Haute_Tarentaise.pdf` : Rapport structuré (méthodologie, résultats, recommandations)
- `PP-Marche-Immobilier-de-Haute-Tarentaise.pdf` : Support de soutenance orale
- `data/` : Données DVF et DPE nettoyées + scoring agrégé par station

## Ouvrir le projet
- Ouvrir le notebook avec Jupyter ou Google Colab
- Ouvrir le `.pbix` avec Power BI Desktop
- Ouvrir le rapport et la présentation avec un lecteur PDF

## Périmètre
Sept stations analysées : Val d'Isère, Tignes, Les Arcs, Peisey-Vallandry, 
La Plagne, La Rosière, Sainte-Foy-Tarentaise.
